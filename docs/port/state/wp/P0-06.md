## Goal

Every size, font and color the UI uses comes from one place, matches the original exactly, and scales with zoom (75–150%) and density. Accent-derived colors are computed exactly as the original does.

## You own

- `Sources/FTFoundation/Design/`.
- `Tests/FTFoundationTests/Design/`.
- `Tests/Golden/accent.json` and `Tests/Golden/css-tokens.json`.
- `tools/tokens/`.

## Do

1. **`tools/tokens/extract-css.ts`** (Bun).
   - Reads the reference `apps/desktop/src/renderer/styles.css` at the pinned commit. Use the reference build at `~/Library/Caches/filetrail-port/reference/electron`, or `git -C /Users/tcmudemirhan/src/tsproj/filetrail show e4d0872:<path>`.
   - Extracts every custom property defined on `:root` and in the light and dark theme blocks, with its resolved value. Resolve `var()` references and `color-mix()` where the inputs are known; mark the rest `unresolved` with the expression.
   - Writes `Tests/Golden/css-tokens.json`. It must be idempotent.
2. **`tools/tokens/accent-golden.ts`** (Bun).
   - Imports the reference's `renderer/lib/accent.ts` and `renderer/lib/theme.ts`.
   - Records their outputs for the 9 preset accents plus 300 seeded random hex colors, in light and dark.
   - Writes `Tests/Golden/accent.json` with cases `{ input, output }`.
   - A harness with a shared golden format is being built in parallel (P0-04, `tools/parity/`). Keep your generator self-contained; it will be moved under that harness later.
3. **`Sources/FTFoundation/Design/`.** Platform-neutral: no AppKit import. Colors are an `RGBA` struct of Doubles (sRGB 0–1); `FTAppKit` will convert them.
   - **`DesignTokens`:**
     - the type scale, radii, control heights, spacing scale and motion durations from `docs/port/inventory/ui.md` §5;
     - every light and dark color from §5.5;
     - the layout constants from §1.1, §1.2, §1.3, §2.1–2.3 (tree/inspector min/max, resizer, row heights per density, icon-grid metrics, list column defaults/min/max, compact list metrics, toolbar constants).
   - **`Metrics(zoom:density:)`** returns every metric and font size scaled by `zoom / 100`, rounded the way the original's layout rounds them. Check the cited TS layout files (`renderer/lib/layoutTokens.ts`, `iconGridLayout.ts`, `detailsLayout.ts`, `flowListLayout.ts`, `topToolbarLayout.ts`). Under web zoom, CSS px scale linearly; mirror whatever rounding those files do.
   - **`AccentPalette(hex:appearance:)`** is a port of `accent.ts`: solidButton, selectionBg, softBg, border, ringSoft, activeBg, folderTint, solidDark, pathCrumbHover, and the dark-theme rename mark. It uses the same contrast math and step loops.
4. **Tests (Swift Testing).** Load the goldens by path from `#filePath`: they live in `Tests/Golden/`, outside every target. A shared loader is being built in parallel; don't depend on it.
   - Every case in `accent.json` matches exactly (hex strings equal).
   - Every token in `css-tokens.json` has a Swift counterpart with an equal value. Map the names in one table in the test file; a CSS token with no Swift counterpart fails the test, unless it is listed with a reason as not used by the native UI.
   - Zoom and density: for 75, 90, 100, 110, 125 and 150 percent, and Comfortable and Compact, every metric equals the original's value × zoom with the original's rounding. These tests replace zoomed and Compact screenshots (PLAN.md §5.4).
