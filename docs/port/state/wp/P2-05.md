## Goal

The system integrations, ported exactly:
- **Open:** default app; Open With lists (default app agreement, apps intersected across items, Launch Services order, pinned apps, kinds); Always Open With (refused for folders); the Other… app picker; open with an app; Finder means reveal.
- **Terminal and editor:** Open in Terminal (the folder, or a file's parent; the `terminalApp` preference) and Edit in the text editor.
- **Clipboard:** Copy Path / Copy Name, with shell quoting only when the path has whitespace.
- **Trash:** Trash state (`~/.Trash` and `/Volumes/*/.Trashes/<uid>`; `.DS_Store` doesn't count; null without Full Disk Access); Empty Trash through Finder via `NSAppleScript` with the same timeout; the Full Disk Access settings link.
- **Disks:** `diskHasTrash` and disk ids.
