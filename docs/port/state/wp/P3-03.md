## Goal

Paste execution, ported exactly, except Replace and crash recovery (P3-04).
- **Execution** (`executeCopyPasteFromAnalysis`):
  - create, merge, Keep Both and Skip;
  - folder copies built under a hidden name and put in place (`executeStagedDirectory`, §3.2 hidden names, §3.3 exclusive renames);
  - large files (32 MiB and more) copied under a hidden name;
  - per-file cut, and the same-disk rename fast path;
  - cross-disk moves: copy, check the copy, then remove the originals (`removeMovedSources`, file-operations.md §3.4);
  - symlinks and their own xattrs, folder metadata after contents, utimes on moves, locked items, packages, other disks.

  - each question gets a fresh id;
  - the answer is registered before the question goes out, and checked against the allowed answers;
  - "apply to the rest of this operation" answers later conflicts of the same kind (`autoResolve`);
  - a runtime Keep Both name avoids later items.
- **Stop** (§3.7) and **progress events** (§3.8), in the original's order and cadence.
