## Goal

The bottom layer of the write engine, ported exactly. P3-02 to P3-08 build on it, so every call must behave as the original's under stop, full disk, locks and odd file systems.
- **System calls** (`FTOperations/Native/`), as file-operations.md §6 lists them:
  - `copyfile` with `COPYFILE_ALL | CLONE | NOFOLLOW_SRC | EXCL | DATA_SPARSE` and a status callback. The callback quits during `COPY_DATA` when the stop flag is set, counts the bytes copied, skips xattr errors except the resource fork's, quits on data errors, and never retries a write that hit ENOSPC.
  - Folder metadata: `copyfile(COPYFILE_METADATA | NOFOLLOW_SRC)`, with the chmod + utimes fallback.
  - `renamex_np(RENAME_EXCL)`, falling back to lstat + rename on ENOTSUP.
  - `lchflags` get and set.
  - ACLs: `acl_get_link_np(ACL_TYPE_EXTENDED)` with `acl_to_text`; `acl_from_text` or `acl_init(0)` with `acl_set_link_np`.
  - `pathconf(_PC_CASE_SENSITIVE)`, where EINVAL means unknown.
  - AppleDouble volumes: `getattrlist VOL_CAP_INT_EXTENDED_ATTR` plus the 4-byte magic.
  - Package detection (`nativeIsPackage`) is already done: `FolderLoader` in FTAppKit uses `.isPackageKey` and T-3056a773 passes. Don't port it again.
  - `FileManager.trashItem(at:resultingItemURL:)`, with native_trash.m's error mapping (Cocoa codes to errno, -1426 to ENOTSUP, `cocoaCode` and the localized description kept).
  - Errors carry the errno name and message exactly as `native_errors.c` builds them.
- **Stoppable copy**: `stoppableCopy.ts` over the copyfile wrapper. It covers the stop flag, progress bytes, a stop before the start, and another error winning over a stop. A copy blocks one thread the caller supplies; it never runs on the main actor.
- **Identity and fingerprints**:
  - `copyPasteFingerprint.ts`: file and symlink fingerprints, missing fingerprints, identity sets, each item read once. Directory fingerprints compare identity only (dev:ino/kind), never mtime (file-operations.md §8 note 4).
  - The `fileIdOf` rule: an inode of 2^53 or more counts as unknown (file-operations.md §8 note 2).
  - Item ids (`itemIdOf`, `readItemId`, `readFolderId`, `readItemRef`, `sameItemId`), `readItemStamp`, `readItemIdAndStamp`, `stampWithoutId` and the undo log entry types from `undoLog.ts`. Stamp entry counts skip the files Finder writes on its own (§8 note 5). P3-03 and later record into them.
  - `describeCopyPasteError`.
- **Trash wrapper**: `createTrashItem` (bootstrap `trashItem.ts`) over the native call, using `DiskHasTrash` (P2-05) to tell a disk that may have no Trash.

Put the copyfile status callback in `CFileTrail` if C is clearer (PLAN.md §3.1).

**Throughput budget** (PLAN.md §4): add a large-file test that copies the same file with the stoppable copy and with a bare `copyfile` call. The bare call uses the same flags and no callback. The two must be within 5%. Other agents' builds load the machine while this runs: alternate the two copies, take the median of at least 5 runs each, and compare medians, so a scheduling spike can't fail it.
