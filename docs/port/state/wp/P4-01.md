## Goal

The app shell, ported exactly:
- **Startup:** launch arguments (`--folder` or a positional folder, `~` expanded); single instance via LaunchServices; the app stays open with no window; Dock click and Dock menu (New Window); disk images opened from Finder (`application(_:open:)` wired to P2-03's service, queued until windows exist); quit and close while busy (the question texts per operation kind; the wiring to the write coordinator is P3-05's, so expose a hook); logging wiring (P2-07's logger); appearance (theme) at launch.
- **The menu bar:** every menu, item, key and visibility rule, built from P1-03's command table and shortcut resolution. That includes the Undo/Redo pairs (files vs text field), the window-targeting rules (the focused explorer window, the front one while Settings has focus, none while all are minimized), and menu state reported per window.
