## Goal

The paste review, ported exactly: the analysis report, the policy that resolves it, and the analysis half of the write service.
- **Analysis report** (`buildCopyPasteAnalysisReport`): the conflict tree, conflict classes, issues and warnings, with the write service's thresholds (100 items, 1 GiB). It covers:
  - file/file, folder/folder and type mismatch;
  - a package reviewed as one item;
  - symlinks, case-only and normalization-only names, AppleDouble companions, `.DS_Store`;
  - into-itself and nested picks;
  - a copy into the same folder (duplicate naming), a cut into the same folder (self target);
  - locked and unreadable items;
  - same disk or another disk.
- **Policy** (`resolveAnalysisWithPolicy`, `resolveNode`): the policy plus per-item overrides become resolved nodes with actions and destinations. The choices offered come from `FTFoundation` `CopyPasteChoices`/`CopyPastePolicy`, and Keep Both names from `CopyPasteNames` (P1-01). Don't port those again.
- **Write service, analysis half** (`writeService.ts`): analysis jobs (start, cancel, prune while keeping the ones asked for, owner); one analysis at a time; refused while a write runs; unknown ids refused. Bring the shared types over from `writeServiceTypes.ts`.
