## Goal

File icons, kinds and thumbnails, ported with the same keys and look:
- **Icons:** `NSWorkspace` icons cached by the original's keys (`ext:`, `kind:`, `path:`), including the generic-kind sample trick.
- **Kind strings:** Spotlight `kMDItemKind`, then the fallbacks.
- **Thumbnails:** `QLThumbnailGenerator` with the same icon mode for non-media, at most 4 at a time, an LRU of 500, and versions by mtime and size, so an unchanged file isn't redrawn.

## You own

- `Sources/FTFileSystem/Icons/`, `Tests/FTFileSystemTests/Icons/`.

## Port

- `packages/native-fs/src/native_fileicon.m`, `native_thumbnail.m` (thumbnails and `nativeKindForPath`).
- The icon and thumbnail handlers in `apps/desktop/src/main/bootstrap/systemHandlers.ts`.
- `apps/desktop/src/renderer/lib/fileIcons.tsx` and `fileThumbnails.tsx` (cache keys, sizes, preloads, concurrency).

Return `NSImage`; there's no need for the original's PNG round-trip.
