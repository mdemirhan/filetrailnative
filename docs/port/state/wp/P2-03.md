## Goal

Volumes, eject and disk images, ported exactly:
- **Volume list:** `getmntinfo(MNT_NOWAIT)`, `/Volumes` only, with physical disk and ejectable found through IOKit or DiskArbitration; refresh on mount changes and window focus; natural sort.
- **Eject:** DiskArbitration unmount with force, whole disk, the internal-ENOTSUP-is-success rule and the 120 s timeout; Finder's busy texts; eject planning ("Eject All" vs this volume only).
- **Disk images:** `hdiutil` isencrypted → imageinfo → attach, hand-off to DiskImageMounter, the busy guard, the open-file entry point API (wiring the app delegate to it is P4-01), and the disk-image extension list.
