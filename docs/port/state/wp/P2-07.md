## Goal

The app's own files, ported exactly:
- **`app-state.json`:** same path layout under Application Support for the dev bundle id, the same JSON, atomic writes (`.tmp` then rename), the two save tiers (150 ms prompt; 5 min deferred for navigation keys, folder visits and window records), dirty tracking, flush on quit, per-window sessions, `lastClosedWindow`.
- **Window bounds:** the bounds-recording rules.
- **`visited-folders.json`:** the one-folder-per-line JSON.
- **The logger:** line format; rotation at 5 MB keeping 10 files; debug lines only with `FILETRAIL_DEBUG` or `FILETRAIL_DEBUG_TIMINGS`; timing lines; serialized writes with flush. Also mirror to `os.Logger`.
