## Goal

How the person moves around and picks items, ported exactly (B-SEL, B-NAV):
- **Selection model** (ui.md §2.6, `contentSelection.ts`, `entryItemEvents.ts`):
  - paths, anchor, lead, and the `gapIndex` where removed items stood;
  - ⌘ toggles, ⇧ extends in visual order; a plain click on one of several narrows on click, not on press, so a drag can carry the whole selection;
  - empty space clears;
  - double-click activates; ⌘-double-click opens a folder in a new tab;
  - select all, and keeping the selection valid as the list changes;
  - selecting tens of thousands of items at once without a stall.
  - this replaces P5-03's selection type; keep the list drawing on it.
- **Marquee** (`dragSelection.ts`): 4 pt threshold; replace, ⇧ add, ⌘ toggle; auto-scroll; the box colors.
- **Keyboard:**
  - arrows, Home and End, ⇧ extends;
  - paging: a full page, and half pages with ⌃U/⌃D;
  - revealing the lead (B-SEL "Keeping the lead in view");
  - Tab switches between the tree and the list;
  - who has the keyboard: panes versus text fields (`focusedEditTarget.ts`, `explorerPaneFocus.ts`);
  - the window's shortcuts from the resolved shortcut table (`useExplorerShortcuts.ts`), with keys a text field keeps left to it.
  - Define a small layout-navigation protocol (next index for an arrow, page size). Implement it for the List here; P5-04 implements it for Icons and Compact List.
- **Type to filter** (ui.md §2.6, `ListFilter` from P1-02):
  - typing narrows the list and selects the best match; ⌫ edits; Esc restores;
  - Space counts as text for 1 s after the last typed character, otherwise it is Quick Look;
  - the filter pill at the bottom center reads "Filter <text> n of N", with clear;
  - it clears on a folder change; ⌘F turns it into a search (the search itself is P5-07's).
- **Inline rename** (ui.md §2.6, B-SEL "Inline rename", B-VIEW §9):
  - Return or F2, as the Return-key setting says;
  - the field is 20 pt tall; it selects the stem for files and the whole name for folders;
  - Return or blur commits, Esc cancels, and an unchanged or empty name cancels;
  - a refused name keeps the field open with a red ring and the error popup under it;
  - the draft survives scrolling;
  - several selected items open Batch Rename (P6-03's sheet; send the command).
  - The commit goes through a seam (a closure on the window) that P3-06 connects to the write coordinator.
- **Open and Return** (B-SEL "Open, Return…", B-NAV §6): open, open in a new tab or window, Return as Open or Rename, `openItemLimit`, folders versus files versus packages.
- **Navigation** (B-NAV §1 to §5, §8, §11 to §16):
  - per-tab history with push, replace and skip;
  - Back and Forward restore each folder's selection and scroll (`folderViewMemory.ts`);
  - the enclosing folder selects the folder you came from;
  - the Go menu places (`GoMenuPlaces`, already in `FTFoundation/Ranking`; use it, don't copy it);
  - startup navigation, through P4-04's `StartupTabs`;
  - folder visits recorded for Go To (`FolderVisitTracker` in `FTFoundation/Ranking`, `AppStateStore.recordFolderVisit`);
  - "does not auto-select the first item" after navigation.
- **Per-tab state** (B-VIEW-164..167, 169, 170): leaving a tab captures its state, and showing it puts everything back; the keyboard goes back to the pane the tab had it in; hidden files and Folders First per tab; the nearest existing folder when the tab's folder is gone.
- **Budget:** Back to a small folder in ≤ 10 ms to drawn (PLAN.md §4).
