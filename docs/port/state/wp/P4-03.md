## Goal

The app's look and its own small windows, ported exactly, plus one clean-up:
- **Theme**:
  - Auto, Light or Dark (default Auto), applied with `NSApp.appearance` and followed live while Auto (B-DLG-232, 234). `AppDelegate.applyAppearance` exists.
  - Windows other than explorer windows get a background of #161618 (dark) or #f4f5f8 (light).
- **Accent**:
  - Any hex color, with the derived colors from `AccentPalette` (P0-06): solid button, selection background, soft background, borders, rings, folder tint (ui.md §5.6).
  - Build `Sources/FTAppKit/Appearance/`: one app-wide object that holds the current `ThemePalette` and `AccentPalette` for the effective appearance and tells every open window to redraw when either changes (B-DLG-233, 245).
  - It also gives P5 the selection colors: accent selection with white text in the focused pane; `--bg-active-inactive` when the pane is unfocused or the window is inactive (F-932, `windowActivity.ts`).
  - Never use `controlAccentColor` or the system selection highlight (PLAN.md §3.5).
- **Preference changes reach every window.** Nothing creates a `WindowPreferenceChannel` yet. Make one for the app, and route its `onPreferencesChanged` to the appearance object and to every explorer window. P5-01's toolbar Theme button and P6-04's Settings then change the look through it.
- **About** (B-DLG §18, ui.md §7.2):
  - 460×356, not resizable; icon, title, tagline and rows;
  - Copy Details, with "Copied" for 1500 ms; GitHub, Report an Issue, Acknowledgements; Esc closes; one at a time.
  - About File Trail opens this window, not the standard panel.
  - Version and commit come from the bundle (`CFBundleShortVersionString` plus a commit key `scripts/build-app.sh` writes; ask under sharedFileRequests). macOS version and architecture, and the fd version.
- **Acknowledgements** (ui.md §7.3):
  - 620×640, min 460×360; intro paragraph; a disclosure list of name, version and license; an expanded entry shows its URL and its license text (max 300 tall).
  - The list is generated at build time from what the native bundle ships: fd and its licenses in `Resources/fd/licenses`. A missing license fails the generator, as `thirdPartyLicenses.ts` does.
- **Help** (B-DLG §17, ui.md §7.1):
  - 900×680, min 560×420; a sidebar of 208 pt (188 when narrow) with "Search help" and the five topics; the content column max 720.
  - `helpContent.ts`, with `{commandId}` replaced by the command's current keys, or its menu path (`ShortcutDisplay`).
  - The Keyboard shortcuts page with keycaps; search; the empty-result text; the wide, narrow and compact layouts (`responsiveLayout.ts`); the last topic remembered.
  - "Customize…" sends `openSettings` for the Shortcuts tab (Settings itself is P6-04's).
  - File Trail Help and Keyboard Shortcuts open it.
- **No zoom in Metrics** (D-005):
  - Replace `Metrics(zoom:density:)` with `Metrics(density:)`, and drop `ZoomScale`, `zoomPercent`, `zoomRange`, `scale` and `scaled(_:)`.
  - The `zoomPercent` preference is still read and ignored.
  - If `DesignTokens.swift` must change, describe the edit under sharedFileRequests.
  - Mark the zoom rules and rows N/A citing D-005: F-588, F-651, F-931, B-DLG-240..243, and the zoom half of B-DLG-259.
