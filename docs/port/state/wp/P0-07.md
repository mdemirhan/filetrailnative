## Goal

A benchmark run that every phase gate can repeat, and that fails on budget misses or on regressions against the last accepted baseline (PLAN.md §4).

## You own

- `Sources/FTAppKit/Debug/Benchmark.swift`. Move the spike's `Benchmark` enum there.
- `Sources/FTAppKit/AppDelegate.swift`, only to remove the moved code and add the new flags.
- `tools/bench/`, `docs/port/bench/`.

## Do

1. **App-side flags** (any build):
   - **`--bench <folder>`**: as today, but also print one JSON line prefixed `BENCH ` with every timing.
   - **`--bench-launch`**: quit right after the first folder is drawn, printing a `BENCH` line with the time from process start (`ProcessInfo` / `kinfo_proc` start time) to first draw.
   - **`--bench-scroll <folder>`**: scroll the List view from top to bottom programmatically, then print the frame-time max and 99th percentile, measured with a `CVDisplayLink` or `CADisplayLink` callback and main-thread stalls.
2. **`tools/bench/run.sh [--quick] [--report-only] [--update-baseline]`:**
   - Builds the release app (`scripts/build-app.sh release`) and runs each benchmark against `~/Library/Caches/filetrail-port/fixtures/bench/` (300, 3k, 30k, 100k items).
   - Measures cold launch (median of 5, after `purge` is not possible; just run 5 times and take the median), and idle memory after 3 s in Home (`footprint` or `vmmap --summary`, physical footprint).
   - Reads the bundle size with `du`.
   - Writes `build/bench/latest.json`.
   - Compares with `docs/port/bench/budgets.json` (the numbers in PLAN.md §4) and `docs/port/bench/baseline.json`.
   - Prints a compact table: metric, value, budget, baseline, verdict.
   - Fails on a budget miss or a regression of more than 10%, unless `--report-only` is given.
   - `--quick` uses only the 3k folder and 3 runs.
3. **`docs/port/bench/budgets.json`.** Create it from PLAN.md §4. Create `baseline.json` from a run on the current spike (`--update-baseline`).
