## Goal

Search, ported exactly on the bundled `fd` 10.5.0:
- **Invocation:** the same arguments for every option (pattern mode, match scope, recursive, hidden, skip `.git`, skip gitignored, `--exclude /Volumes` at `/`, smart case).
- **Results:** NUL-separated streaming into an `AsyncStream`, batched for the UI; the 20,000-result cap with truncation; SIGTERM on cancel; every `fd` killed at quit; cleaned stderr errors.
- **Result items:** path, name, extension, kind, hidden, parent path and relative parent.
- **Results lists:** sorting and the "src › renderer" folder column.
- **Bundling:** `fd` is bundled into the app and signed.
