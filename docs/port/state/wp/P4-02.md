## Goal

Windows and tabs on native macOS window tabs (PLAN.md §3.4), with the original's behavior:
- **Per tab (one `NSWindow` each):** folder, history, tree root, view, sort and search.
- **Per tab group:** the panels shown, pane widths, column widths and Reopen Closed Tab list. These are shared through a `TabGroupSession`.
- **Tab labels:** search-tab and duplicate-name labels, and "Macintosh HD".
- **Limits:** the 100-tab limit with its notice.
- **Window commands:** New Window, Open in New Window, Move Tab to New Window and Merge All Windows, as our own actions with the busy, sheet and limit rules.
- **Session restore:** windows, tabs, front tab, bounds and maximized state, in the same `app-state.json` window records (P2-07); `lastClosedWindow`; cascaded placement of new windows (+22 pt).
- **Closing:** closing the last window keeps the app running; ⌘W on the last tab closes the window.
- **Running operations:** an operation is handed to a successor window when its window closes. Expose the hook; P3-05 wires it.
