## Goal

Make the disk-image test helper reliable. `DiskImageSelfTests` failed twice in CI, then passed on a rerun: once in `detachesWhenTheBodyThrows` and once in `mountsWritesAndDetaches(kind: .hfs)`. Both failures say the image path still existed right after detach (`Tests/FTTestSupport/LargeFileTests.swift:27` and `:41`).

## You own

- `Tests/FTTestSupport/DiskImage.swift`, `Tests/FTTestSupport/LargeFileTests.swift`.

## Do

1. Find why: `hdiutil detach` returning before the clone file can be removed, a mount still busy (Spotlight or fseventsd), or tests running in parallel on the same clone path.
2. Fix it at the cause. Use unique clone paths, wait until the device is gone (poll `hdiutil info -plist` with a short bounded timeout), and retry the detach with `-force` once. Don't paper over it with sleeps.
3. Run the self-tests 30 times in a loop (`swift test --filter DiskImageSelfTests` repeated) and report the pass count. It must be 30 of 30.

## Gate

- `for i in $(seq 1 10); do swift test --filter DiskImageSelfTests >/dev/null 2>&1 || exit 1; done`
- `scripts/ci.sh`
