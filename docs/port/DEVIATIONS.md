# Deviations from the original

Each entry is an intentional difference between the native port and the Electron app. Each one is **proposed** until the user approves it at a wave gate.

| ID | Area | Original | Native port | Why | Status |
|---|---|---|---|---|---|
| D-001 | Tabs | In-window tab strip; tab context menu has Duplicate Tab | System tab bar; Duplicate Tab only in the File menu and its shortcut | Native window tabs chosen on 2026-10-13 | approved (decision) |
| D-002 | Tabs | Middle-click closes a tab | Not available; ⌘W or the tab's close button | The system tab bar owns tab clicks | approved 2026-10-13 |
| D-003 | Tabs | Hovering a file drag over a tab for 700 ms switches to it | Not available | The system tab bar owns drags over tabs | approved 2026-10-13 |
| D-004 | Drag | `system:readDragChangeCount` throws (addon export missing), so the "same drag came back" check never runs | The check works, using `draggingSequenceNumber` | A bug in the original, not a behavior | approved 2026-10-13 |
| D-005 | View | Whole-window zoom 75–150% (View › Zoom In/Out/Actual Size, ⌘+ / ⌘− / ⌘0, a zoom setting in Settings) | Not available; the UI is fixed at the original's 100% metrics. The `zoomPercent` preference is still read when importing settings and is ignored | Decided by the user on 2026-10-13: not worth the complexity | approved 2026-10-13 |
| D-006 | Batch Rename | Regex patterns run on JavaScriptCore; an invalid pattern's message is the engine's text | Patterns run on `NSRegularExpression` after translation (`JSRegExp`). The text after "The pattern isn’t valid: " is the port's own wording. A few edge cases still differ: a back reference to a group that took no part fails instead of matching empty; `\P{Lu}` under `i`; captures of empty loops such as `(a*)*`; look-behinds of unbounded length; a ligature like ﬁ in a character class also matching "fi" | No JavaScript regex engine in the system frameworks; whether a pattern is valid matches on every tested pattern (P1-04) | proposed |
| D-007 | Settings | A saved text setting cut at 255 UTF-16 units inside an emoji keeps half the surrogate pair | The broken half becomes U+FFFD | A Swift string cannot hold a lone surrogate (P1-04, P2-07) | proposed |
| D-008 | Paste | Keep Both with a copy number of 2^53 or more on a taken name loops forever | Stops after a bounded number of attempts and reports that no free name was found | A hang in the original, not a behavior (P1-05) | proposed |
| D-009 | Folder sizes | Finished folder sizes are polled every 200 ms | They arrive as soon as they finish, at most every 20 ms; the sizes are the same | Native worker notification replaces polling (P2-02) | proposed |
| D-010 | Trash | An Empty Trash error reads like `0:46: execution error: … (-1712)` (osascript) | Reads `execution error: … (-1712)`, without the source-range prefix | NSAppleScript instead of the osascript tool (P2-05) | proposed |
| D-011 | Search | Match highlighting uses JavaScript regex semantics | Interim: highlighting uses `NSRegularExpression`; possessive quantifiers and `(?i)` groups are refused by hand, other ICU-vs-JavaScript syntax differences remain. P5-07 switches it to `JSRegExp`, which removes this entry | `JSRegExp` was internal to FTFoundation when fd search was ported (P2-06) | proposed (interim) |
| D-012 | Menus | Full screen is a hidden menu item with ⌃⌘F | AppKit's own View › Enter Full Screen item, same key | Native apps get it from AppKit; hiding it fights the system (P4-01) | proposed |
| D-013 | Tabs | Tabs can't be dragged between windows or out into a new one | The system tab bar allows both; the port turns a dragged-out tab into a full explorer window and merges a dropped tab into the target window | Native window tabs (D-001) own tab drags (P4-02) | proposed |
| D-014 | Windows | The window's title is the front tab's label, so the Window menu, ⌘\` and Mission Control show labels like "fixtures — filetrail-port" or “q” in src | The Window menu and the Dock's window list show the tab label; Mission Control and the accessibility title show the folder name, which is also the toolbar title | With native tabs, `NSWindow.title` is the toolbar title too (P4-02) | proposed |
